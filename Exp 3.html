LAMP and WAMP Stacks

A simple guide to their components, installation, and the role of the Apache web server.

1. Key Components of the LAMP Stack

LAMP is a group of open-source technologies commonly used to build and run dynamic websites and web applications on Linux.

L — Linux

Operating system

Manages hardware, files, processes, users, and system resources.

A — Apache

Web server

Receives HTTP requests from browsers and serves webpages or passes dynamic requests to PHP.

M — MySQL

Database

Stores and retrieves structured application data, such as users, products, and orders.

P — PHP

Server-side language

Runs application logic, processes forms, communicates with the database, and generates dynamic pages.

Typical installation on Linux (Ubuntu/Debian)

Open a terminal and install the components using the package manager:

sudo apt update
sudo apt install apache2 mysql-server php libapache2-mod-php php-mysql

Start and enable the services, then check Apache in a browser at http://localhost:

sudo systemctl enable --now apache2
sudo systemctl enable --now mysql

For a simple PHP test, create /var/www/html/info.php with <?php phpinfo(); ?> and visit http://localhost/info.php. Remove this test file after testing because it reveals configuration details.

2. Key Components of the WAMP Stack

WAMP provides a similar web development environment on Microsoft Windows.

W — Windows

Operating system

Provides the platform on which the development tools and services run.

A — Apache

Web server

Accepts browser requests and serves files or runs server-side application code.

M — MySQL

Database

Stores and manages the application's data.

P — PHP

Server-side language

Processes application logic and creates dynamic responses.

Typical installation on Windows

  1. Download a reputable WAMP package, such as WampServer, from its official website.
  2. Check the package's Windows and runtime prerequisites, then run the installer.
  3. Choose the installation folder and complete the setup.
  4. Start the WAMP services and confirm that the server indicator shows that services are running.
  5. Open http://localhost in a browser to test the local server.
  6. Place project files in the WAMP web directory, commonly www, and test the application.

Installation screens and folder locations can vary by WAMP package and version. Use the official package instructions and avoid exposing a development server directly to the internet.

4. Role of Apache Web Server

Apache HTTP Server is the web-server component in both LAMP and WAMP. It connects the browser to the application running on the server.

  1. Receives requests: A browser sends an HTTP request for a page or resource.
  2. Serves static files: Apache can return HTML, CSS, JavaScript, and image files directly.
  3. Runs dynamic applications: With PHP configured, Apache passes PHP requests to the PHP handler for processing.
  4. Works with MySQL: PHP application code communicates with MySQL to read or update data.
  5. Sends responses: Apache returns the generated page or other response to the browser.
